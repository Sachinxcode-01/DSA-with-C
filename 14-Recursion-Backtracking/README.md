# 14 - Recursion & Backtracking

Backtracking is an algorithmic technique for solving problems recursively by trying to build a solution incrementally, piece by piece, removing solutions that fail to satisfy constraints at any point in time.

---

## 📚 Key Concepts

- **Recursion Tree & State Space Search**
- **Decision State**: Choose, Explore, Un-choose (Backtrack)
- **Base Conditions & Pruning**

---
