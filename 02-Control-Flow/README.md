# 02 - Control Flow & Loops

Control flow structures dictate how programs make decisions, repeat operations, and branch based on conditions.

---

## 📚 Key Concepts

- **Conditional Statements**: `if`, `else if`, `else`, and ternary operator `? :`
- **Multi-way Branching**: `switch-case` with `break` and `default`
- **Loops**:
  - `for` (counter-controlled iteration)
  - `while` (pre-tested condition loop)
  - `do-while` (post-tested loop, executes at least once)
- **Jump Statements**: `break`, `continue`, `goto` (and why to avoid `goto`)

---
